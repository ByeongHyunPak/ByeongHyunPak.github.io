# Byeonghyun Pak Academic Website

This repository hosts the personal academic website for Byeonghyun Pak.

The site is built from the [PRISM](https://github.com/xyjoey/PRISM) academic homepage template with local content managed in:

- `content/config.toml`
- `content/bio.md`
- `content/publications.bib`
- `content/news.toml`
- `content/about.toml`
- `content/publications.toml`

## Development

PRISM expects Node.js 22 or later.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is exported to `out/`.
